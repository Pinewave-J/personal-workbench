# 个人工作台（投标 / 任务 / 客户）· 使用说明

> 前端（HTML 结构 + 独立 CSS / JS / 配置）+ Node.js + SQLite（Node 内置 node:sqlite，零原生依赖），本地单机运行，无需联网。
> 含投标登记、任务&待办（四象限 + 每月周期任务）、客户档案与跟进、系统图谱、备份恢复、全局搜索与 CSV 导出。

---

## 一、快速开始

### 1. 环境要求
- Windows / macOS / Linux 均可
- 安装 [Node.js](https://nodejs.org) **v22.5 及以上**（需内置 `node:sqlite`，建议 v25，本包在 v25.2 验证）

### 2. 启动后端
```bash
cd backend
npm install        # 首次运行，仅需安装 express
npm start          # 监听 http://127.0.0.1:8787
```
看到 `[personal-workbench] backend ready` 即成功。**此窗口保持打开。**

> 无 npm 时也可直接运行：`node --disable-warning=ExperimentalWarning src/index.js`
> 改端口：`$env:PORT=9000` 后启动（Windows PowerShell）或 `PORT=9000 npm start`（macOS/Linux）。

### 3. 打开前端
- **普通浏览器**：直接双击/打开根目录的 `personal-workbench.html`（前端经 fetch 访问 127.0.0.1:8787 后端；浏览器直接打开 file:// 即可，无需 Web 服务）。
- **DeepSeek Harness 工作台**：将 `widget-result.json` 放入 DSH 站点目录，或在工作台窗口选择本 HTML 文件挂载。

### 4. 数据存放
- 数据文件：`backend/data/workbench.db`（SQLite 单文件）。首次启动自动建表，仅当对应表为空时插入演示数据；**已有数据不会被覆盖**。
- 开标结果上传文件存于 `backend/uploads/`。
- 完整备份/恢复、模块 CSV 导出都在前端「设置」页操作。

## 二、功能一览

| 模块 | 能力 |
|---|---|
| 个人总览 | 磁贴导航 + **日历**（每天要办的事）+ 项目状态分布环形图（6 类口径，含历史）+ 行业分布环形图 + 今日提醒 + 投标动态 2×2 |
| 首页日历 | 月视图聚合四类事项：任务/待办、投标截止与开标、日程提醒、客户跟进；点某天看当天明细、可勾完成、可「在这天新增待办」 |
| 待办看板 | 重要/紧急四象限、状态 待办/进行中/已完成/已取消、截止日与提前提醒、周期实例自动生成 |
| 周期任务 | 每月固定任务模板（每月第 N 天），进入待办页自动生成本月实例，可单独完成 |
| 客户档案 | 客户 CRUD（潜在/跟进中/已成交/暂停/流失），行业自由填写 |
| 跟进记录 | 记录跟进 → 填下次跟进日期自动生成待办；完成该待办可填新日期回写客户，闭环联动 |
| 投标工作台 | 项目登记（类别/行业/预算/保证金/报价）、状态机流转、文件夹链接、日程提醒、开标结果上传预览、统计分析 |
| 系统图谱 | 6 张 archify 交互式图谱：投标状态机 / 客户跟进闭环 / 周期任务幂等 / 系统架构 / 备份恢复数据流 / 开标结果链路（自带深浅主题、缩放、搜索与导出） |
| 系统 | 操作日志、设置（备份 v2 / 覆盖恢复 / 模块 CSV 导出 / 投标数据导入 / 外观主题） |
| 外观主题 | 顶栏「浅色/暗色」一键切换（设置页也有入口）；选择记在浏览器本地，图表配色随主题自动切换 |
| 全局搜索 | 顶栏跨模块搜索（投标项目 / 任务 / 客户） |

### 界面与图表

- **主题**：默认「暗色霓虹」（已定稿的配色，未做任何改动）；可切到「浅色」，适合办公、投屏、打印场景。首屏前写入主题属性，切换不会闪屏。
- **首页环形图**：段间留 2px 视觉留白（不改变占比），鼠标悬停某段或图例项时，其余变淡、**中心数字切换为该段数值**，图例带同色占比条。
- **统计页**：状态分布 + **行业分布**（化工石油 / 工业厂房 / 新能源…，空行业归「未填写」）改为带刻度的横向条形图（数值 + 占比 + 悬停提示）。颜色与首页行业环形图一致。
- **四象限**：首页改为 2×2 矩阵，位置即语义（左上=重要紧急），并显示每个象限的行动建议（立即去做 / 列入计划 / 委托速办 / 删减稍后），点击进入看板。
- **投标概览**：整宽上下排列 —— 上为「近期开标日程」（显示招标人 / 地区 / 剩余天数，≤3 天高亮，点击直接打开该项目），下为「最近登记的项目」表格；窗口变窄时次要列（预算）自动隐藏。
- **首页日历**：磁贴下方一整张卡。四类事项按**发生/截止的那一天**分桶：任务（按四象限配色）、投标截止与开标（同一项目合并为一条，不重复）、日程提醒、客户下次跟进。
  - 点某天 → 卡片内展开当天明细（点已选中的那天回到今天）；明细里可**勾完成**（客户跟进任务会弹「下次跟进日期」）、可「打开」到对应弹窗。
  - 「＋ 在这天新增待办」会把**截止日预填**为所选日期。
  - 逾期未办的待办**仍显示在原定日期**（不搬到今天），同时在今天明细顶部汇总一条「逾期未办 N 件」；窄窗口（<760px）自动切换为按日期分组的清单。
  - 工具条：上下月、「今天」、四类显示开关、「只看未完成」、折叠；这些偏好记在浏览器本地。
- **系统图谱**：左侧清单切换，右侧 iframe 内嵌图谱（每张约 610KB，按需加载）。图谱是**独立文档**，自带深度/浅色主题、缩放、搜索与导出，可按「在新窗口打开 ↗」全屏看。改过后端逻辑需重新生成，命令见 `graphs/README.md`。
- **窄窗口适配**：窗口宽度 <1180px 时侧栏自动收成图标条，<860px 时表单与栅格改为单列。

### 投标状态机
`跟踪中 → 已报名 → 已购标书 → 已投标 → 已开标 → 中标 / 未中标 / 流标`，终态不可再流转；列表内下拉即可流转。

### 金额单位
库内以**元**存储；前端与 CSV 导出以**万元**显示/呈现（JSON 备份为元原值）。

## 四、常见问题

| 现象 | 处理 |
|---|---|
| 页面提示无法连接后端 | 确认后端已 `npm start` 且 8787 未被占用（改 PORT 需同时改 `personal-workbench.config.js` 里的 `API_BASE`） |
| 导入 CSV 金额不对 | CSV 金额列按**万元**；JSON 按**元** |
| 恢复备份 | 设置 → 完整备份恢复（覆盖式，操作前先导出当前备份） |
| 数据想重置 | 停后端后删除 `backend/data/workbench.db`，重启即重建演示数据 |

问题反馈：携带浏览器控制台报错 + 后端窗口日志。
